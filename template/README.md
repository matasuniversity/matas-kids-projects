# Назва навчального проєкту

Скопіюйте цю папку в корінь нового репозиторію та замініть демонстраційні значення у `matas-project.json`. Нові проєкти використовують `schemaVersion: 2`. `id` стабільний; назва/опис/напрям непорожні. Фото — відносний шлях PNG/JPEG/WebP/SVG без `..`. `skills` — потрібні навички, `team` — true/false, `instructions` — кроки.

## Електроніка зі складу

Спочатку додайте всі потрібні компоненти до складу локації та позначте їх як електроніку для проєктів. У списку складу є «Скопіювати ID». Вставте стабільні ID та кількість у маніфест:

```json
"electronics": [{ "itemId": "ID-зі-складу", "quantity": 2 }]
```

Не додавайте окрему ціну проєкту чи `materialsCostUah`. Платформа обчислює вартість за поточною ціною кожного компонента на складі, показує потрібну кількість і нестачу. Ціни рахуються до копійки. Залишок 0 дозволений: товар зберігає ID і історію. Відсутній ID, обладнання або витратник без ознаки електроніки не дозволяють імпорт. Якщо електроніка не потрібна, залиште `electronics: []`; тоді вартість 0 грн.

ID належать складу конкретної локації. Для імпорту до іншої локації спершу переконайтеся, що там є такі самі ідентифікатори; автоматичного зіставлення за назвою немає. Зміна ціни складу змінює поточний розрахунок, але не попередні списання. Публікуйте лише ID матеріалів; не додавайте особисті дані дітей.

## Результат та етапи

Опишіть, що дитина створить і що має продемонструвати. Збережіть інструкцію у JSON; тут можна додати схеми, моделі й код. Платформа читає маніфест і зображення, не виконує код.
