# Назва навчального проєкту

Скопіюйте цю папку в корінь нового репозиторію та замініть демонстраційні значення у `matas-project.json`. `id` має бути стабільним; назва/опис/напрям — непорожні; вартість матеріалів — оцінка гривень до копійок. Фото — відносний шлях PNG/JPEG/WebP/SVG без `..`. `skills` — потрібні навички, `team` — true/false, `instructions` — масив кроків. Нульова оцінка в шаблоні означає незаповнене значення, замініть її перед включенням у навчальний каталог.

## Результат

Опишіть, що дитина створить і що має продемонструвати.

## Матеріали та інструменти

Перелічіть потрібні компоненти. Вартість фактичної видачі розраховує платформа зі складу; оцінка в JSON не створює списання.

## Етапи

Збережіть інструкцію у JSON; тут можна додати детальні пояснення/схеми/код.

## Файли

Додайте моделі, схеми й код у зрозумілих папках. Платформа читає маніфест і зображення, не виконує код. Не публікуйте особисті дані або персональні результати дітей у цьому спільному шаблоні.
