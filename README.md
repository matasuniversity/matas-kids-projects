# MATAS Kids — projects

Каталог посилань на репозиторії проєктів і шаблон для створення нового проєкту. Персональних дитячих даних тут немає. Власні проєкти дітей, закупівлі/списання/залишки зберігає платформа.

## Створити проєкт

1. Створіть окремий GitHub-репозиторій для навчального проєкту.
2. Скопіюйте **вміст папки `template/`** у корінь нового репозиторію.
3. Додайте електроніку до складу локації, позначте її як електроніку для проєктів та скопіюйте ID зі списку. У `matas-project.json` schemaVersion=2 заповніть `electronics: [{itemId, quantity}]`; окрему ціну не вказуйте. Платформа обчислює ціну й нестачу зі складу. Змініть зображення, інструкції й файли моделі/коду.
4. Додайте посилання в `projects.json` цього каталогу.
5. У платформі: Директор → GitHub-контент → Проєкти → Прочитати GitHub → перевірити попередній перегляд → застосувати каталог.

Приклад запису (замініть власником/репозиторієм, це не готове посилання):

```json
{
  "schemaVersion": 1,
  "projects": [
    {
      "repoUrl": "https://github.com/OWNER/PROJECT",
      "commit": "40-символьний-sha-коміту"
    }
  ]
}
```

`commit` можна не вказувати: платформа прочитає HEAD та зафіксує знайдену версію при імпорті. Для узгодженої навчальної програми рекомендується зазначати commit і змінювати його після перевірки нової версії. Початковий список порожній: справжніх посилань власник ще не надав. Шаблон сам по собі не є навчальним проєктом і не включений до каталогу.

До30 проєктів за імпорт у поточній демоверсії. Однакові посилання заборонені; всі файли перевіряються до застосування, помилка одного проєкту не змінює каталог. Видалений запис архівується для нового вибору, але вже призначені дітям проєкти та історія матеріалів зберігаються. Код репозиторіїв не запускається.

Шаблон знаходиться в підпапці, тому цей каталог **не позначений GitHub Template**: нативний Template копіює цілий репозиторій. Коли знадобиться «Use this template», краще винести `template/` в окремий `matas-kids-project-template`. Це додатковий репозиторій, зараз не створений.

Локальна перевірка: `node scripts/validate.mjs`. Приватні проєкти потребують майбутнього серверного доступу; токени не додавайте в JSON або браузер. Не публікуйте контакти, імена/фото дітей, їх баланси або особисті роботи без окремого дозволу.
